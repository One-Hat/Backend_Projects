## Reporting a Vulnerability

If you discover a security vulnerability within any project in this repository, please report it privately:

- **Email**: `swapnil7x@gmail.com`
- Please provide detailed reproduction steps, sample payloads, and the affected endpoint/service.
- We aim to acknowledge reports within 48 hours and patch confirmed issues promptly.
