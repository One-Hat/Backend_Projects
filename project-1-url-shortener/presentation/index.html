Full-Stack URL Shortener

High-throughput link redirection, cryptographically random alias generation, schema validation, and real-time click tracking.

Architecture

System Architecture

Client-server decoupling with Express REST API and React 18 frontend.

Express REST API

Handles POST /shorten to generate aliases and GET /:code for HTTP 302 browser redirections.

Zod Validation

Fail-fast middleware validating inbound URL parameters before processing.

React 18 (Vite)

Real-time interactive dashboard displaying short links, copy-to-clipboard, and click analytics.
